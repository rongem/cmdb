# Project DataCenter Manager
The idea behind the cmdb projects is to have on backend that gives unified access to the data and acts as a single source of truth. It serves for multiple frontends or connectors that deliver their data into the database.

The project DCMan comes in where automatic connectors like the one to VMware VCenter are unable to deliver data. The pure asset management, handling all the hardware, is made simple by the DCMan. It allows you to create models for each hardware type, add assets and put them into racks or blade enclosures. A simple graphical interface lets you view all your assets as you would do in real world. Also connections to logical items, like servers, are possible.

DCMan is expandable and configurable. You can choose your own name for configuration item, connection and attribute types, so translate it into the language you prefer.

A search is not yet implemented, but will be added soon.
