The main search will be done over the free text search field. Text in the field will be searched as part of every configuration item's name or attribute value. An auto complete displays existing values in the data after typing at least 3 characters.

The attributes' search allows you to search for special attribute content only in selected attribute types. A starting exclamation mark (!) negates the search, so all attributes that do not contain the string will be found. A single exclamation mark finds all attributes that are not empty, while an empty field finds non-existing attributes.

Connections can be searched for a special type or - if there is more than one item type possible for that connection type - for all types that can be connected via this connection type. You may choose if you search items that do not have a connection of that type (0), that have at least one (>0), exactly one (1) or more than one (>1) connection.

Finally you can choose to find only configuration items that you are responsible for. It is willingly impossible to find other responsiblities.

You must set at least one search parameter to execute a search. If you do this, a [result list](How-to-use-CMDB-=-Search-results) will be displayed, or an error message if no configuration item meets all of your criteriae.
